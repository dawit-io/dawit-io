## 🌍 Flui — Modern deploys. Your cloud. Your servers.
 
[![License: AGPL v3](https://img.shields.io/badge/License-AGPLv3-blue.svg?style=for-the-badge)](https://www.gnu.org/licenses/agpl-3.0)
[![Docs](https://img.shields.io/badge/docs-flui.cloud-326CE5?style=for-the-badge&logo=readthedocs&logoColor=white)](https://docs.flui.cloud)
[![Kubernetes](https://img.shields.io/badge/built_on-K3s-326CE5?style=for-the-badge&logo=kubernetes&logoColor=white)](https://github.com/flui-cloud/core)
 
**Flui** is an open-source, EU-sovereign cloud orchestration platform. Deploy modern apps on your own servers — or any provider — without lock-in. One `flui.yaml`, your infrastructure, full control.
 
**What I'm building into Flui:**
- 🤖 **Idempotent by design** — a stateless, in-cluster MCP server is the single action surface; the CLI and external agents (Claude Code, Codex, Gemini CLI) all drive the same operations, safe to re-run
- 🌐 **Cloud-provider agnostic** — your apps aren't tied to any single cloud; run and move them across providers from one spec
- 🪐 **The Universe canvas** — an interactive control surface where clusters are galaxies, servers are stars, and apps are planets
- 🇪🇺 **Residency enforced at the orchestration layer** — sovereignty by design, not by promise
The `flui.yaml` spec is an open, vendor-neutral standard (Apache 2.0) — Flui is the reference implementation.
